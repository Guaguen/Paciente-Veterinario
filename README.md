# Veterinaria Pacientes

## Descripción

En el proyecto se desarrollo un sistema para administrar pacientes veterinarios

## Tecnologías Utilizadas

- Java
- INtelliJ

## Requisitos Previos

- Intellij

## Instalación

1. Clona este repositorio:git@github.com:Guaguen/Paciente-Veterinario.git

-


2. Navega a la carpeta del proyecto:

    - Proyecto


3. Abre el archivo src en IntelliJ
## Uso

Explica cómo usar tu proyecto:

1. Abre Main.java ejecuta en run

1. Registrar nuevo paciente.
2. Mostrar pacientes registrados.
3. Eliminar paciente por nombre.
4. Calcular el promedio de edad de los pacientes

## Características

- Menú interactivo por consola 
- Calculo
